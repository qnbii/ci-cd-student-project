# CI/CD Student Project

![CI Status](https://github.com/qnbii/ci-cd-student-project/github/workflows/ci.yml/badge.svg)

Простой проект для демонстрации CI/CD pipeline с автоматическим тестированием.

Критерии оценки
Отлично (5 баллов):
•	Все файлы проекта созданы корректно
•	Workflow успешно выполняется без ошибок
•	Тесты проходят на всех версиях Python
•	Реализованы все три jobs (test, lint, security)
•	Бейдж статуса отображается корректно
•	Код хорошо откомментирован
Хорошо (4 балла):
•	Основной workflow работает корректно
•	Тесты проходят на большинстве версий Python
•	Реализованы минимум 2 jobs
•	Проект структурирован правильно
Удовлетворительно (3 балла):
•	Workflow запускается, но есть незначительные ошибки
•	Основные тесты проходят
•	Реализована базовая функциональность
